# Sayfit Studio Documentation

این پوشه مرجع اصلی مستندات پروژه است. مستندات عملیاتی Codex در `CLAUDE.md` ریشه باقی می‌ماند؛ مستندات سایت و روند توسعه فقط در این پوشه نگهداری می‌شوند.

## نقشهٔ مستندات

- [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) — ساختار فایل‌ها و نقش هر بخش
- [ARCHITECTURE.md](ARCHITECTURE.md) — معماری استاتیک، جریان داده و قوانین تغییر
- [CONTENT.md](CONTENT.md) — محل نگهداری متن‌های انگلیسی و فارسی
- [I18N.md](I18N.md) — قوانین ترجمه و زبان راست‌به‌چپ
- [APPS.md](APPS.md) — مدل محتوای اپ‌ها
- [SEO.md](SEO.md) — متادیتا، sitemap و صفحات تولیدشده
- [PROJECT_PAGES.md](PROJECT_PAGES.md) — ورودی‌ها، خروجی‌ها و بازسازی صفحات Work
- [MEDIA.md](MEDIA.md) — تصاویر، CDN و `projects.json`
- [DEPLOYMENT.md](DEPLOYMENT.md) — روند انتشار روی هاست
- [TESTING.md](TESTING.md) — تست‌های اجباری قبل از تحویل
- [UX_ARCHITECTURE.md](UX_ARCHITECTURE.md) — معماری صفحات، مسیر کاربر و قواعد UI/UX
- [CONVERSATION_LOG.md](CONVERSATION_LOG.md) — خلاصهٔ درخواست‌ها و گفت‌وگوهای مؤثر بر پروژه
- [qa/README.md](qa/README.md) — خروجی‌ها و محدودیت‌های کنترل بصری این نسخه
- [CONTRIBUTING.md](CONTRIBUTING.md) — قرارداد تغییرات و مستندسازی
- [DECISIONS.md](DECISIONS.md) — تصمیم‌های مهم ثبت‌شده
- [CHANGELOG.md](CHANGELOG.md) — تاریخچهٔ تغییرات

## قانون ساده

هر متن جدید باید در منبع زبان خودش نوشته شود؛ متن انگلیسی در فایل `en` و متن فارسی در فایل `fa`. متن‌های HTML فقط fallback یا shell هستند و منبع محتوای قابل ترجمه محسوب نمی‌شوند.
